3Overhaul · one coherent system

Five rules drive this pass. One primary action per screen (a docked bar in detail, a single FAB in lists). Status is never colour alone — dot plus word, and the group header carries it so rows stay quiet. Two facts of metadata per row, maximum. Every choice becomes a bottom sheet instead of a menu, so the thumb never reaches the top of the screen. Chrome collapses: the three filter chips become one filter button with a count, and grouping moves into view options.
